# Fichajes-Maker

Aclaración importante sobre seguridad: Si visitáis mi repositorio de código, veréis que he incluido las credenciales de la base de datos directamente escritas en los archivos. He decidido hacerlo así exclusivamente por motivos didácticos. De esta forma, cualquier persona que se inicie en estos temas puede descargar el proyecto, probarlo y entenderlo a la primera. Sin embargo, en un entorno de producción real, estos secretos nunca van en el código. En mi infraestructura de Azure, las contraseñas están guardadas en la bóveda de seguridad y se inyectan a la aplicación mediante Variables de Entorno invisibles desde fuera
Por otro lado, esta estructura de ficheros es un proyecto EDUCATIVO y no se debe aplicar a un entorno real
